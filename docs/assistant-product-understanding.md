# Как развивать понимание запросов в помощнике

## 1. Запоминать названия, подтверждённые пользователем

- После выбора предложенных позиций и расчёта дать отдельное действие «Запомнить название».
- Хранить пользовательскую фразу и подтверждённые названия из чеков в локальном хранилище настроек. Дать открыть список, изменить формулировку и удалить связь.
- В запросах суммы и количества сверять всю товарную фразу с сохранёнными названиями. Учитывать базовые изменения падежа. Общий запрос «молоко» охватывает своё множество покупок, даже если сохранена фраза «чудо молоко».
- Подставлять выбранные названия в расчёт по строкам чеков. Период и магазин брать из текущего вопроса. Сохранённые связи остаются на устройстве.
- Проверить повторный запрос с новым периодом или магазином, расчёт по двум названиям, широкий запрос и отсутствие подходящих чеков. Проверить сохранение и управление связями.

## 2. Разбирать намерение и уточнения

Закрепить в слое помощника отдельные поля действия, товара, единицы, периода и магазина. Сохранять смысл предыдущего запроса для уточнений вроде «А в октябре?». Проверить, что ответ различает сумму, штуки и известный объём.

## 3. Подбирать варианты по смыслу

Сначала ограничить выборку периодом и магазином. Для неоднозначных формулировок передавать провайдеру короткий список кандидатов по идентификаторам, через существующий клиент. Показывать отправленные сведения в «Что ушло в ИИ». Проверять ответ модели по этому списку и считать итог локально по подтверждённым строкам.

## 4. Связывать названия из новых чеков

Добавить каталог в слое данных, сохраняя исходные строки. Использовать бренд, вид, вкус, фасовку и штрихкод, когда они известны. Добавление сомнительного совпадения в подтверждённую группу требует выбора пользователя. Если потребуется менять схему Room, включить миграцию, схему и тест миграции.

Слой интерфейса показывает выбор и подтверждение. Слой помощника разбирает запрос и считает результат на Kotlin. Слой данных отвечает за хранение. Для каждого этапа проверять сценарии с несколькими товарами, вкусами, фасовками и магазинами.
